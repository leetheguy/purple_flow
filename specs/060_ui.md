# 060 — UI

Status: implemented
Created: 2026-09-25

Phoenix LiveView, modeled on n8n's executions view: pick a past run and see every step's input and output. This is for viewing runs, not editing workflows. Workflows are edited in TOML.

## Pages

1. **Workflows**: every loaded workflow, its triggers, its last run status, and a "Run" button with a JSON input box.
2. **Runs** for a workflow: newest first, showing status, start time, and duration. New runs appear live (`"runs"` topic).
3. **Run detail**: one row per step, in workflow order.

## Run detail

- **Collapsed row:** step name, status color, duration, and item count if it ran per item (`save ×10 — 9 ok, 1 failed`).
- **Expanded row:** input and output as pretty JSON, or the error.
- **Per-item step:** expands into one indented row per item. Each of those expands to show its own input and output and which earlier item it came from.
- **Colors:**
  - green: ok
  - red: failed or timed out
  - blue: running
  - gray: didn't run
- **Live:** if the run is still going, rows update as `step_finished` messages arrive on `"run:<run_id>"`.

Gray just means the workflow has a step with no saved rows. It's not tracked anywhere.
